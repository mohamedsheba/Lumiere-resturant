# Lumière Restaurant

A modern and responsive restaurant website built as a personal frontend project.

The project focuses on creating a clean restaurant experience with a strong visual design, responsive layouts, and interactive elements using HTML, CSS, and JavaScript.

## Live Demo
https://mohamedsheba.github.io/Lumiere-resturant/

## Features

- Responsive design for desktop, tablet, and mobile devices
- Light and dark mode
- Navigation menu with mobile layout
- Hero section with restaurant introduction
- Featured dishes section
- Menu section with different food categories
- About the restaurant and chef section
- Table booking form
- Blog section
- Smooth navigation between sections
- Interactive UI elements using JavaScript
- Decorative shapes and visual elements to enhance the design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- SVG

## Design

The website was designed with a focus on creating a modern restaurant identity while keeping the interface simple and easy to navigate.

The layout was built with responsive behavior in mind, with different arrangements and spacing for smaller screens rather than simply scaling down the desktop layout.

## Purpose

This project was created as a personal practice project to improve my frontend development skills, especially in:

- Responsive web design
- CSS layouts and positioning
- Creating modern UI designs from scratch
- JavaScript DOM manipulation
- Theme switching
- Building reusable and organized sections
- Designing interfaces for different screen sizes

## Status

This is a personal frontend project and is not an official restaurant website.

The project can be extended in the future with features such as a real booking system, user authentication, online ordering, and backend integration.
